# Age & Countdown Widget (Android)

Open this folder in Android Studio (Koala or newer), let Gradle sync, then Run.
Add widgets from the app's buttons or from the home screen widget picker.

- Sizes: 1x1, 2x1, 3x1, 2x2, 3x2
- Tap a widget: open its settings. Swipe up/down: next page (age / total days / next birthday or weeks left)
- Settings: age or exam countdown, date + time, years/months/days/time toggles,
  compact (28.6) or detailed (28y 6m), transparent or coloured background, opacity, text colour
